# 网络搜索

> 没有一条帆船能吹动自己行驶，它需要外面的风。 -- 因可觅[《量子离歌》](https://read.douban.com/ebook/12945743/)

网络搜索本身是一个很重的服务，它包含三项核心任务：网页爬取、网页索引和网页检索。**网页索引** 几乎只能由大公司完成。即使 [SearXNG](https://github.com/searxng/searxng) 这样的开源检索方案，也只是聚合第三方搜索引擎（如必应、搜狗）的结果，没有独立索引能力。因此，即使独立开发网络搜索功能，也难以绕开大公司的服务。不如一开始就老老实实用大公司的 API，来获取搜索结果。

本节介绍四种网络搜索方式：

- 使用 [DashScope](https://dashscope.aliyun.com/)
- 使用 [Tavily](https://www.tavily.com/)
- 使用 [DDGS](https://github.com/deedy5/ddgs)
- 使用 [Exa MCP](https://exa.ai/mcp)

**DashScope** 是阿里的 MaaS 平台，由于我们已经有了阿里的 `API_KEY`，这对我们是最轻松的方式。**Tavily** 是 LangChain [推荐](https://docs.langchain.com/oss/python/integrations/retrievers/tavily) 的搜索服务，有免费额度，但需要花时间申请 `API_KEY`。**DDGS** 是一个免费的搜索引擎，不需要 `API_KEY`，但搜索结果的质量较差。**Exa** 的普通 REST API 免费额度需要 `API_KEY`，但官方公共 MCP 服务目前可以免 `API_KEY` 使用。

下面来看这三种搜索服务的使用方法和效果。


```python
import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain.tools import tool

# 加载模型配置
_ = load_dotenv()

# 加载模型
llm = ChatOpenAI(
    model="qwen3.7-flash",
    temperature=0.7,
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url=os.getenv("DASHSCOPE_BASE_URL"),
)


def brief(message, max_chars: int = 400):
    """展示辅助：截断过长的工具结果，避免搜索结果刷屏，其余消息原样返回。"""
    if message.type != "tool":
        return message
    content = message.content
    if isinstance(content, list):  # 内容块列表，先拼接为纯文本
        content = "".join(block.get("text", "") for block in content if isinstance(block, dict))
    if not isinstance(content, str) or len(content) <= max_chars:
        return message
    snippet = (
        content[:max_chars] + f"\n\n…（工具结果共 {len(content)} 字符，仅展示前 {max_chars} 字符）"
    )
    return message.model_copy(update={"content": snippet})
```

## 一、使用 DashScope

首先安装 OpenAI SDK：

```bash
uv sync
```

DashScope 已提供兼容 OpenAI Responses API 的联网搜索工具。对于 `qwen3.7-flash` 这类多模态模型，应使用 Responses API 的 `web_search` 工具，而不是旧版 `Generation.call` 文本生成接口。下面把搜索调用封装成工具供 Agent 使用。


```python
from openai import OpenAI

dashscope_client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url=os.getenv("DASHSCOPE_BASE_URL"),
)


@tool
def dashscope_search(query: str) -> str:
    """
    使用夸克搜索 API 搜索互联网信息。
    """
    response = dashscope_client.responses.create(
        model="qwen3.7-flash",
        input=query,
        tools=[{"type": "web_search"}],
    )
    return response.output_text


# 创建 Agent
agent = create_agent(
    model=llm,
    tools=[dashscope_search],
    system_prompt="你是一个智能助手，回答前必须使用工具搜索互联网信息",
)

# 运行 Agent
response = agent.invoke(
    {"messages": [{"role": "user", "content": "告诉我今天的日期，以及今天最重要的一条新闻"}]},
    version="v2",
).value
```


```python
# 获取 Agent 的全部回复（工具结果过长时仅展示开头部分）
for message in response["messages"]:
    brief(message).pretty_print()
```

## 三、使用 DDGS

首先安装 DDGS：

```bash
uv sync
```

我们直接使用 DDGS 获取的摘要信息，没有做进一步网页爬取。下面将 DDGS 做成工具。


```python
from ddgs import DDGS

# 创建 ddgs 客户端
ddgs = DDGS()


@tool
def ddgs_search(query: str) -> str:
    """
    使用 DDGS 搜索 API 搜索互联网信息。

    Args:
        query: 搜索关键词或问题。
        max_results: 返回的最大结果条数。

    Returns:
        包含每条搜索结果的标题、摘要与链接的字符串。
    """
    results = list(
        ddgs.text(
            query=query,
            region="wt-wt",  # wt-wt zh
            timelimit="y",
            safesearch="off",  # moderate off
            page=1,
            backend="auto",
            max_results=3,
        )
    )

    content = ""
    for i, r in enumerate(results, 1):
        content += f"【结果 {i}】\n"
        content += f"标题: {r['title']}\n"
        content += f"摘要: {r['body']}\n"
        content += f"链接: {r['href']}\n\n"

    return content


# 创建 Agent
agent = create_agent(
    model=llm,
    tools=[ddgs_search],
    system_prompt="你是一个智能助手，回答前必须使用工具搜索互联网信息",
)

# 运行 Agent
response = agent.invoke(
    {"messages": [{"role": "user", "content": "告诉我今天的日期，以及今天最重要的一条新闻"}]},
    version="v2",
).value
```

## 四、使用 Exa MCP

[Exa](https://exa.ai/) 是面向 AI 应用的搜索服务。它的普通 REST API 提供免费额度，但仍需要注册并创建 `API_KEY`；如果希望免 `API_KEY` 体验，可以使用官方提供的公共 [Exa MCP](https://exa.ai/mcp) 服务。

LangChain 1.4 起内置了 MCP 适配器。`langchain.mcp` 命名空间当前仍为 **Beta**，API 可能继续调整；这里使用当前稳定包内的最新接口。安装带 `mcp` extra 的 LangChain：

```bash
uv sync
```

然后直接连接 `https://mcp.exa.ai/mcp`。这段代码不读取 Exa API key，服务端会提供 `web_search_exa` 和 `web_fetch_exa` 两个工具。公共服务的免费策略可能调整，生产环境仍应使用自己的 Exa API key。

Exa 的搜索与网页抓取结果动辄上万字符，因此下面的展示用 `brief()` 截断了工具结果。



```python
from langchain.mcp import MCPAdapter

# Exa 公共 MCP：无需配置 EXA_API_KEY
exa_adapter = MCPAdapter("https://mcp.exa.ai/mcp")
exa_tools = await exa_adapter.list_tools()

exa_agent = create_agent(
    model=llm,
    tools=exa_tools,
    system_prompt="你是一个智能助手，回答前必须使用 Exa 搜索互联网信息，并附上来源链接",
)

response = await exa_agent.ainvoke(
    {"messages": [{"role": "user", "content": "告诉我今天的日期，以及今天最重要的一条新闻"}]},
    version="v2",
)
response = response.value
```


```python
# 获取 Agent 的全部回复（工具结果过长时仅展示开头部分）
for message in response["messages"]:
    brief(message).pretty_print()
```

## 五、四种方式对比

本章对四种搜索方式提了同一个问题：「告诉我今天的日期，以及今天最重要的一条新闻」（运行当天为 2026-09-11 周五）。结果对比：

| 方式 | 日期 | 数据质量 |
| -- | -- | -- |
| [DashScope](https://dashscope.aliyun.com/) | ✅ 答对 | 服务端联网搜索，返回当日整合内容（9·11 事件 25 周年纪念） |
| [Exa](https://exa.ai/) | ❌ 差一天 | 权威媒体全文（路透社、中新网），中英双语检索，原始数据最扎实 |
| [DDGS](https://github.com/deedy5/ddgs) | ❌ 差一天 | 真实新闻源（新闻联播、人民日报），但搜索快照滞后一天 |
| [Tavily](https://www.tavily.com/) | ❌ 错 8 天 | 返回万年历表格与页面噪音，本次表现最差 |

三家纯搜索 API 以**三种不同方式**栽在「今天」这个词上：Exa 从文章发布时间推断日期（最新报道是昨天的）、DDGS 的搜索快照滞后一天、Tavily 把「今日日期」理解成万年历查询。只有 DashScope 的 `web_search` 是服务端搜索——服务端知道当前时间，返回的已是当日整合内容。这是结构性差异，不是运气。

选型建议：

- **时效性问题**（今天天气/新闻）：用 [DashScope](https://dashscope.aliyun.com/) 的 `web_search` 工具
- **知识/技术检索**（文档、博客）：用 [Exa](https://exa.ai/)，[公共 MCP](https://exa.ai/mcp) 可免 `API_KEY` 体验
- **RAG 场景**：用 [Tavily](https://www.tavily.com/)，它专为 RAG 优化（本章的失败源于时间敏感查询，并非它的典型场景）
- **免费无 `API_KEY`**：用 [DDGS](https://github.com/deedy5/ddgs)
